## Пример кода

Функция для поиска максимального числа в массиве:

```javascript
function findMax(numbers) {
  let max = numbers[0];

  for (let i = 1; i < numbers.length; i++) {
    if (numbers[i] > max) {
      max = numbers[i];
    }
  }

  return max;
}

console.log(findMax([3, 7, 2, 10, 5])); // 10
```
